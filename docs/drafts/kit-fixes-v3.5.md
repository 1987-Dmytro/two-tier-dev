## 1. Хост вкладки Code, мод `handoff`, поле сжатия (к F1)
- **Как вкладка запускает движок** (снято с живой сессии): `claude --output-format stream-json --verbose --input-format stream-json --model=claude-opus-5-5 --permission-prompt-tool=stdio --setting-sources=user,project,local --permission-mode=auto --include-partial-messages --await-initialize --replay-user-messages --settings {…}` — без `-p`.
- **Хост пробы** — те же флаги без `--permission-prompt-tool` и `--await-initialize`; сообщения — строками JSON в stdin: `{"type":"user","message":{"role":"user","content":[{"type":"text","text":"…"}]}}`; лог движка — `--debug-file <файл>`; `SPEC_GATE=off`, без `ANTHROPIC_API_KEY`. Проект — свежий клон telefon `main`, профиль `.claude/settings.local.json` = его `launch.settings.json` (порог мода в профиле 40, в личных настройках оператора 70).
- **Строки движка, мод 0.3.0 как установлен** (плагин читается прямо из рабочего дерева кита — marketplace-каталог `mods/`: правка мода на диске попадает в каждую новую сессию вкладки оператора):
  - `hooks module handoff@two-tier-mods loaded (worker, environment 1, tier user); events: session.start,turn.start,classic.SessionStart,turn.complete,command.run,ui.render`
  - `session.start: raised (surface none, not interactive)`
  - `$.command.register (window-guard): /window listed` · `… (phase-start): /phase listed` · `… (spec-board): /board listed`; строки `$.command.register (handoff)` нет.
- **Команды** приходят событием `system/commands_changed` (в `system/init` команд модов ещё нет): `phase`, `board`, `window` — есть, `handoff` — нет. Сообщение `/handoff status` ушло модели обычным текстом.
- **Опции мода.** С записью в личных настройках движок об опциях молчит; без неё пишет `plugin handoff: no pluginConfigs["handoff@two-tier-mods"].options in user, --settings or managed settings (project settings are not read); every option is its default`. Порог 40 из профиля проекта до мода не доходит.
- **Проба ретро — копия мода, где команда регистрируется всегда:** `/handoffp status` → `handoff · context 2% of 1000000 tokens · threshold 40% · auto-clear on · dir handoffs/ · last: —` (порог подан через `--settings`); `/handoffp now` → `$.model.fork` 9,4 с → файл в `handoffs/` → `conversation_reset trigger=clear` → сообщение мода о свежем контексте → сессия продолжила.
- **Поле сжатия.** Без поля: `autocompact: tokens=… level=ok effectiveWindow=980000`. С `"autoCompactWindow": 600000` в `.claude/settings.local.json` проекта: `effectiveWindow=580000` (запас движка 20 тыс.). На пороге движок пишет `autocompact: routing through reactive (thresholdSource=settings)` (проба ретро на 100000: восемь `compact_boundary trigger=auto` у 72–79 тыс. токенов).
- **Ряд SPEC-11 для порога 40 %:** после сжатия первый запрос 103–127 тыс. токенов, за 20 мин 148–426 тыс., за час до 501 тыс.; при 400 тыс. — ранняя оценка ≈ 20 хендоффов на фазу такого размера. Мод 0.3.0 взводится снова, когда заполнение упало ниже порога − 20 (`isArmed`), и не срабатывает раньше `minTurns` запросов.
- **Побочный эффект пробы с включённым плагином:** движок дописывает запись в `installed_plugins.json` пользователя (`Added handoff@two-tier-mods installation for scope local (<каталог стенда>)`) — вне объёма v3.5, каталоги стендов держать под `/tmp/two-tier-v3`.
- **Поверхность в хосте пробы.** Приложение подключается к сессии как поверхность `desktop` (типы модов, прочитано 12.11.2026: `session.attach` — «a surface joined the session's roster of attached clients (a phone opened the session; the desktop app connected)»; `$.session.surfaces()` — «Empty in a plain -p run»). Хост пробы делает то же строкой в stdin до первого сообщения: `{"type":"control_request","request_id":"r1","request":{"subtype":"ui_attach","surface":"desktop","client_id":"probe"}}` → `control_response` `success`, `{"surfaces":["desktop"]}`; лог движка: `session.attach: probe on desktop`, моды `window-guard` и `spec-board` получили `session.attach`. С ключом `clientId` движок отвечает ошибкой и называет форму: `surface` — `desktop`, `mobile` или `vscode`, `client_id` — 1–64 знака из букв, цифр, `.`, `_`, `-`.
- **Живая вкладка — «сессия человека» (замер 12.11, движок 2.1.321).** Мод `spec-board` зовёт git только при REPL или подключённой поверхности (`mods/spec-board/hooks/register.tsx`: `isPersons` в `refresh`), раз в 60 с. У движка живой сессии вкладки (проект telefon, без хода) дочерний `git … log --format= --name-only --diff-filter=A -- docs/evidence/verify-*.txt` — аргументы `collect` этого мода — шёл раз в 60,0 с: 5 тиков из 5 за два окна по 150 с. Калибровка на хосте пробы без хода, 140 с: без поверхности после старта — 0 вызовов, с `ui_attach` — вызов на подключении и дальше раз в 60 с. Мод 0.3.0 там же молчал (`isInteractive` false) — значит, условие истинно через поверхность. Строки движка `session.attach` с живой вкладки нет: отладочный лог приложение не ведёт.
