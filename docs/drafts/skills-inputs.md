# Вход в обновление скиллов — копилка уроков (файл тимлида; пополняется на каждой приёмке, разбирается на ретро фазы)

Назначение: чтобы ни один урок не потерялся до ретро. Здесь — кандидаты, не правила. В скилл строка идёт только по §8 `team-lead`: официальный источник Anthropic или повтор ошибки не меньше двух раз; сначала механизм (чек, хук, поле шаблона), проза — когда механизма нет; абляция; «одно вошло — одно вышло». Только паттерны: конкретика проекта остаётся в его PROCESS.

Адресаты: **СПЕК** — будущий отдельный скилл написания спек; **ТЛ** — `team-lead` v6.1; **КИТ** — механизм в ките.
