4. `abide check` судит staged-патч через `--diff` (README Abide: без него — всё рабочее дерево и неотслеживаемые файлы).
5. Пороги F5 — доли `unifiedWindows` × 100 против `*_pct` (statusline-док даёт 0–100, событие — 0–1).
