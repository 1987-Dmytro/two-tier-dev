## 1. Дизайн высокого уровня
Здесь нет условий «готово»: все они — пункты §2.
- **Три заявления — три судьи.** «Кусок готов» — коммит: код и `abide check`. «Фаза готова» — конец хода: `spec-gate`. «Плечо готово» — отчёт фазы тимлиду и один круг `/verify-phase`. Между заявлениями модель-судья молчит.
- **Пункт спеки** — строка вида `F<n>.<k>` под строкой фичи: наблюдаемый результат и место, где он читается. Механизм и пробу выбирает исполнитель в PLAN. Id пункта стоит в сообщении коммита, который его закрывает, и в строке evidence с сырым выводом пробы: по этим двум следам код строит матрицу. Этот SPEC — первый реальный вход разбора пунктов; шаблон SPEC кита получает тот же формат.
- **Проба** — команда с двумя сторонами: зелёная на годном и красная на образце, где результат обязан не наступить. Пробы живут в чеке фичи и гоняются на проекте-фикстуре из кита во `/tmp/two-tier-v3`.
- **Отчёт фазы** — файл в `docs/evidence/`, собранный кодом: матрица пунктов, счёт судей коммита, пропуски хука, статусы Jev.
- **Jev — одна ячейка в тени:** пункт против сырого вывода его пробы, один вопрос на пункт, три ответа. Метки копятся с этой фазы.
- **Рубрика коммита** — файл тимлида: только необратимый вред, у каждого правила красный образец. Всё, что проверяется кодом, проверяет код.
- **Окружение.** Инструмент стоит там, где есть его событие (таблица — research (c), §3).

## 4. Стопы
Стоп — новая строка `STOP: <id>` в `docs/PROGRESS.md`, рядом вопрос и resume-строка, в запушенном HEAD; после неё ход кончается. Причин три; STOP-PAY не нужен — платное только Jev:
- **STOP-SCOPE** — реальная смена объёма или нет документированного способа достичь пункта: цитата источника, альтернатива, вопрос. Расхождение деталей с доком — не стоп, а строка в PLAN.
- **STOP-INPUT** — нужен вход оператора: установка уровня пользователя, блок auto mode без обходного пути, отказ вложенного `claude -p` или `Workflow(verify-phase)`, нет прав `gh`. Строка STOP пишется, когда закрыты и запушены все пункты, которым этот вход не нужен.
- **STOP-NP** — нет прогресса: проба красная три попытки подряд без изменения вывода. Ожидание CI попыткой не считается.
