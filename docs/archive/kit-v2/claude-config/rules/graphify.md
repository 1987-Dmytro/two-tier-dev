# graphify — граф знаний по коду проекта

Секция, которую `graphify claude install` пишет в CLAUDE.md, живёт здесь: CLAUDE.md держит потолок в 40 строк.

**Ставится под названный чек или фичу** (правило Environment в `docs/PROCESS.md`), а не «на всякий случай»: корпус кода должен быть больше того, что удобно читать grep'ом.

Установка и обновление:

```
pip install graphifyy && graphify install      # скилл, не MCP
/graphify src --wiki                           # строить ПО src/, не по всему репо
graphify hook install                          # post-commit, AST, без LLM
```

MCP-режим graphify — **выключен**: он тянет контекст на каждый вызов, а CLI даёт то же самое по запросу.

Как пользоваться в сессии:
- точечный вопрос → `graphify query "<вопрос>"` (узкий подграф) вместо grep по сырым файлам;
- широкий архитектурный контекст → `GRAPH_REPORT.md`, и только для него;
- граф лежит в `graphify-out/`; его отсутствие — не ошибка, значит фаза его не заказывала.

Снять: удалить строку graphify из таблицы Environment и `graphify-out/`; в следующей фазе не ставить, пока её фича его не назовёт.
