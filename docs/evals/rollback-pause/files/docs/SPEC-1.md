# SPEC-1 — rollout — фаза 1

**intent:** — · **дата:** 07.11.2026

## 0. Контекст
Оператору нужна выкатка релиза с откатом: при красном здоровье откат идёт не сразу, а после паузы — стенд успевает остыть.

## 1. Дизайн высокого уровня
`bin/deploy` — скрипт python3 без зависимостей; `bin/check-deploy` — его чек; `bin/gate-1` — гейт фазы.

## 2. Фичи
- **F1 Выкатка** · оператор получает выкатку с откатом · готово: F1.1–F1.2 · чек: `bin/check-deploy` → `DEPLOY_OK` · служит: S1 · after: —
  - `F1.1` `bin/deploy ok` печатает `deploy r2` и `health=OK`, exit 0, строки `rollback` нет
  - `F1.2` `bin/deploy bad` печатает `health=FAIL`, затем пауза отката не короче 1 с, затем `rollback r1`, exit 1: числа `t=<мс>` в начале этих двух строк расходятся на 1000 и больше

## 3. Инварианты и границы
- Только stdlib python3; сеть не нужна.
