# INTENT — two-tier-dev (система разработки «оператор · тимлид · исполнитель»)

**Владелец:** Дмитрий (оператор). **Текст ведёт:** тимлид, по словам оператора. **Подпись:** 10.10.2026, 20:20, «принято» (S8, ретро v3.3); до неё — 09.10.2026, 20:44 (грилинг v3.3). **Прежний intent:** `intent/two-tier-dev-v2.md` (18.09) — история.

## Проблема
v2 лечил разрастание, и оно вернулось: скилл вырос в 7 раз, документов стало впятеро больше кода, приёмка шла дольше плеча. v3 и v3.1 закрыли это механикой. Осталась дыра между «сказал» и «сделал»: конец хода судили по словам исполнителя, проверка по файлам приходила через часы. `/goal`, по оценке оператора, мешает разработке: фазу ведёт правильная спека.

## Желаемый результат
Оператор ведёт любой свой проект циклом intent → прожарка → SPEC → запуск фазы → приёмка → гейт.
- Исполнитель получает результат, проверку, границы и стопы, а путь строит сам.
- Фазу ведёт спека: конец хода держит `spec-gate` по её пунктам, а не по словам; `/goal` в цикле нет.
- Судью зовёт заявление «готово», а не каждое действие; запреты держит код.
- Объём инструкций держит механика, а не память.
- Intent живой и закреплён в SPEC пином.
- Система улучшает себя только по официальным источникам Anthropic.
- Новый проект разворачивает `bin/two-tier-init`, живой переводит `bin/two-tier-upgrade` — одной командой, без потери истории.

## Сигналы успеха
- **S1** — `bin/check-budget` зелёный на ките и в каждом проекте; CI на push зелёный.
- **S2** — обязательное чтение исполнителя на старте — до 50 тыс. знаков: `Read first:` стартового запроса (до 3 файлов) плюс CLAUDE.md; auto memory в ките выключен.
- **S3** — на фазу: стопов, кроме ожидания внешних входов, не больше трёх; блокирующих находок на приёмку — не больше пяти; приёмка тимлида не дольше плеча исполнителя.
- **S4** — коммитов с правкой продукта не меньше, чем коммитов по ревью.
- **S5** — каждая правка скилла или харнеса — в CHANGELOG со ссылкой на официальный источник (или на повтор не меньше двух раз) и с итогом контрольного прогона.
- **S6** — живой проект переведён без потери истории (архив плюс ветка) и продолжает фазу.
- **S7** — фаза не кончается словом «готово» без маркера каждой фичи: конец хода блокируется и называет недостающее; ложных блоков — не больше одного на плечо.
- **S8** — у каждого пункта «готово» своя проба с красной стороной. Находка проверяющих блокирует, когда ломает наблюдаемый результат пункта; мутации кода чека — списком в отчёте круга, решает тимлид. Кругов приёмки — один полный и не больше одного точечного на фичу.

- **N2** — не строим своего оркестратора поверх Claude Code: воркфлоу ultracode — штатный режим, `spec-gate` — Stop-хук, а не цикл.
- **N3** — не переписываем роли брифа.

## Решено и открыто
- **D1** (06.10) — team-lead: до 80 строк и 12 тыс. знаков, только паттерны; правка — на ретро или при новой модели, по официальным источникам, механизмом, с абляцией, «одно вошло — одно вышло».
- **D2** (06.10) — исполнитель в auto mode; доверенная инфраструктура — в `--settings`.
- **D3** (06.10) — intent — один живой файл с пином в SPEC и журналом разворотов.
- **D4** (07.10) — исполнитель под ultracode; приёмка — `/verify-phase`, 30 мин. Планки лимитов подписки сняты 07.10.
- **D5** (09.10) — `/goal` уходит из кита: фазу запускает стартовый запрос в строке запуска, конец хода держит `spec-gate` — кодом, по пунктам спеки в запушенном HEAD; кап блоков и времени, при ошибке пропускает.
- **D6** (09.10, разворот 10.10) — каждому инструменту Jev-слоя — своё событие и свой ярус. У исполнителя коммит судят код и `abide check`, конец хода — `spec-gate`; судей на каждое действие нет. Инструменты хода (Toolgate, Compact Adviser, Steer-or-Queue) — в сессиях оператора; jev-mcp и Quicksilver — тимлиду. Проводка — китом и Environment.
- **D7** (10.10) — гарантия «сделано всё, что в спеке»: пункт «готово» — наблюдаемый результат со своей пробой, механизм выбирает исполнитель; у каждой строки спеки назван судья; рубрика коммита — только необратимый вред, до восьми правил; отказ судьи-модели — один раз, последнее слово за исполнителем; Jev не блокирует, пока порог не поставлен по своим меткам.
- Открыто вне этой фазы: политика планки F1 telefon (STOP-5); хватит ли `autoMode.environment` для ssh и деплоя на сервер проекта.
