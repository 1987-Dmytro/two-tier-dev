# team-lead — the Cowork-side skill card

`SKILL.md` here is the current card. It is installed by saving it as a skill in the Claude account (Cowork proposes
an updated card after every stop; the operator saves it). The version in the frontmatter's `description` is the
version of the whole system; `CHANGELOG.md` at the root says what each version learned.

Rules for changing it:
- Patterns only. A tool name, a flag, a price, a path or a platform word is a defect of the card — it belongs to
  the project's `docs/PROCESS.md` or its phase file. Test: would the line read the same in a project on another
  platform, in another currency, with another executor?
- A change enters through the self-improvement pass (§10): the stop → its class → the rule → where it lives.
  The stop review (`templates/stop-patterns.md`) is the evidence; a rule without a stop that taught it waits.
- The whole card is replaced on save, so a proposal carries the complete file, never a diff.
