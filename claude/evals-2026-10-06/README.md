# Проверка скилла team-lead v6 — 06.10.2026

Скилл меняется только с абляцией (D1, §8 team-lead). Здесь лежат сценарии и утверждения для таких прогонов и итоги перехода v5.2 → v6.

## Метод
Метод — skill-creator и «Demystifying evals»: оценивается результат, а не путь.
- **Сценарии.** Три реальных стопа фазы 1, обезличены:
  - E1 — стоп по деньгам посреди фазы;
  - E2 — красные прогоны на стохастике и приёмка плеча;
  - E3 — kickoff нового проекта с числовой планкой и жёсткими ограничениями.
- **Прогон.** Свежий субагент получает путь к скиллу и сценарию; без веба, памяти и устройств. Ответ пишется в файл.
- **Оценка.** Отдельный грейдер в свежем контексте проверяет ответ по заранее записанным утверждениям (`assertions.json`). «Прошло» засчитывается только с цитатой-доказательством. В итерациях 1–2 оценка шла вслепую: A/B без меток версии.
- **База** — живой v5.2 на 05.10.

## Что поправили по итогам прогонов
- **После итерации 2** (E3 — 6/9) добавлены три правила:
  - допущение по умолчанию на факт, который знает только оператор;
  - жёсткие ограничения закрываются до подбора вендоров;
  - раунд — до ~12 вопросов.

  Итерация 3 — 12/12.
- **Итерация 4** прошла после правок двух верификаторов пакета: владение файлов, коннекторы, публичный evidence, проверка делом. Регрессий нет.
- **Итерация 5** — строка «КОГДА закончим»: дата или диапазон дат; без замеров — ранняя оценка и что её сдвинет. Даты появились в E1 и E2.

## Ограничения
- По одному прогону на конфигурацию: pass^k не мерили.
- Утверждения писал автор скилла. Грейдеры отметили слабые места:
  - счёт строк обходится длинными строками;
  - проверка «свежим контекстом» почти автоматическая, когда сценарий уже даёт вердикт evaluator'а;
  - арифметику утверждения не проверяют. Грейдеры проверили её сами — ошибок нет.
- Сценарии здесь обезличены: названия вендоров и компаний заменены. Прогоны 06.10 шли на исходных текстах.
- Сырые ответы и оценки в репо не кладутся: в них детали клиентского проекта.

## Как повторить — абляция правки скилла
1. На каждый сценарий — два свежих субагента: со скиллом до правки и после. Промпт: «Execute this task as the team lead described by the skill. Skill: <путь>. Companion skills: grilling, team-lead-brief (read only if your skill tells you to). Task: read the scenario file <путь> and do the task described at its end. Rules: work only from these files; no web, no device, no memory; answer in Russian as you would send it. Save to <путь>.»
2. Грейдер в свежем контексте получает сценарий, ответ и утверждения из `assertions.json`. На каждое утверждение — passed и цитата; плюс длина ответа, строки сообщения оператору и дата.
3. Правка входит, если не уронила ни одного утверждения и чинит то, ради чего сделана (D1).
