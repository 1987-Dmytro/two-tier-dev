# Контекст сценария E3 — kickoff нового проекта с числовой планкой

Новый проект: телефонный ассистент для немецкого ремесленного бизнеса — принимает пропущенные звонки, собирает суть обращения, присылает владельцу сводку на почту. Оператор (CTO) открыл сессию словами: «/team-lead — новый проект, начинаем kickoff».

Что оператор сказал в первом сообщении:
- «Бот должен отвечать с задержкой не больше 700 мс — как живой человек, иначе никто не купит».
- «Всё европейское, никаких американцев — критично для наших клиентов».
- «Один провайдер, не два — по деньгам не сходится».
- «Бюджет на весь проект — до 100 €».
- «Склейка — low-code оркестратор; сервер — европейский хостинг (ещё не куплен)».

Известное окружение исполнителя: Claude Code, базовый набор плагинов оператора (Context7, Graphify, Ponytail, security-guidance, code-review) ставится в каждый проект. Кандидат-вендор, который называл оператор: один европейский провайдер ИИ (распознавание речи, LLM, синтез речи).

## Твоя задача
Ты тимлид. Начни kickoff-прожарку по своим скиллам (team-lead + grilling): выдай первый раунд так, как отправил бы оператору. Внешние источники и репозиторий сейчас недоступны — факты, которые надо добыть, назови как задачи на поиск, не выдумывай чисел.
