# Контекст сценария E6 — написать спеку фазы перевода живого проекта

Система: «кит» — набор инструментов, которым заказчик держит харнес в своём репозитории. В ките есть команда `upgrade`: переводит проект со старой версии кита на новую (заменяет файлы кита, переносит настройки, кладёт архив старых файлов). Фаза 5 — «перевод живого проекта заказчика „Склад“ на кит v4». Исполнитель — Claude Code; фазу ведёт спека, конец хода держит Stop-хук по пунктам спеки. Оператор подписал intent (пин `a1b2c3d4e5f6`) и раунд вопросов; ты пишешь SPEC-5.

## Что известно (журнал решений и твои замеры)

- D1. Проект «Склад» переводится на отдельной ветке `upgrade-v4`; `main` меняется только через PR после гейта оператора. История не теряется: старые файлы кита уходят в `docs/archive/`.
- D2. После перевода проект должен продолжать свою текущую фазу: его собственные чеки (`bin/check-budget`, CI) зелёные, стартовая сессия исполнителя в проекте видит хук конца хода и файл правил суда коммита.
- D3. Команду `upgrade` запускает тимлид, не исполнитель; исполнитель чинит то, что после неё красное в проекте, и приводит документы проекта к формам v4.
- D4. Платного в фазе нет. Сеть — только хостинг репозитория.
- Замер 1 (твой, вчера): self-test `upgrade` на синтетической фикстуре кита — зелёный. На свежем клоне «Склада» `upgrade` вышел с кодом 0, но `bin/check-budget` проекта после него — красный: у «Склада» в `budgets.json` свой список файлов тимлида, а коммит `upgrade` кладёт архив в каталог из этого списка без пометки тимлида.
- Замер 2: у «Склада» есть свой файл правил суда коммита с двумя правилами проекта; кит v4 приносит базовый файл из четырёх правил.
- Сигналы успеха intent, которым служит фаза: S1 — чеки проекта и CI зелёные; S6 — живой проект переведён без потери истории и продолжает фазу; S3 — приёмка не длиннее плеча исполнителя, блокирующих на приёмку не больше пяти.
- Прошлое плечо (фаза 4), измерено: стройка 76 мин; полный круг проверяющих 22 мин; точечный круг 12–18 мин; починка 45 мин, из них своё ревью исполнителя 20 мин; на круги в сумме ушло 2 ч 21 мин — три лишних точечных круга по одной фиче находили только мутации кода чека.
- Открыто: нужен ли «Складу» статус-плагин окон подписки (оператор не решил; фазу не держит); порог судьи-модели для отчёта фазы не откалиброван.

## Твоя задача
Ты тимлид. Напиши SPEC-5 по своему скиллу и шаблону кита: §0 кратко, §2 (фичи с пунктами, таблица судей, таблица посадки для планки S3), §3, §4, §5, §6. Пиши так, как положил бы в репозиторий на подпись оператору. Репозиторий недоступен — работай по контексту; чего не знаешь — назови, не выдумывай числа.
