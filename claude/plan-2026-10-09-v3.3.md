## 1. Что строим — пять фич, документы, гейт
| Фича | Что видит оператор | Чем доказано |
|---|---|---|
| F1 «Готово по пунктам» | «Готово» без любого пункта спеки не кончает ход и называет id пункта. В отчёте фазы — матрица «пункт × коммиты, проба, наблюдение» и три списка: пункты без коммитов, коммиты без пункта, пункты без пробы. Jev в тени ставит каждому пункту «подтверждает / противоречит / молчит» | пробы хука обеих сторон; матрицу строит код |
| F2 «Правила на коммит» | Коммит с секретом, файлом тимлида, удалением мимо `git mv` и force-push получает отказ кодом; нарушение правила рубрики — отказ `abide check` один раз, повтор того же диффа проходит с пометкой «отклонил» | красный образец на каждое правило |
| F3 «Окружение по событиям» | У исполнителя нет судей на каждое действие: Toolgate, хуки Abide на правку, Compact Adviser и Steer-or-Queue ушли; Belay — в тени | `check-harness`: ни один хук на действие не ходит в сеть |
| F4 «Один круг приёмки» | `/verify-phase` принимает список фич; выжившая мутация — блокирующий кандидат; проверяющие строят свои фикстуры | фикстура с выжившей мутацией |
| F5 «Окна до запуска» | Строка запуска отказывает при занятом окне подписки и называет число | проба с подставленным значением окна |
| Документы и гейт | CHANGELOG со свипом источников; гейт кита на пустом репо | `bin/gate-v3.3` |

Правила постановки (D-а…D-е), по которым пишется SPEC-v3.3:
- Пункт «готово» — наблюдаемый результат с условиями наблюдения (где читается, на какой фикстуре); механизм выбирает исполнитель в PLAN.
- У каждой строки спеки назван судья: «нельзя» — правило рубрики или код; «должно работать» — проба с красной стороной; сила пробы — проверяющий и мутации; «заявлено = показано» — Jev в тени. Строка без судьи красная до запуска.
- Рубрика — короткая база проекта: только необратимый вред, не больше восьми правил, у каждого красный образец. Из сегодняшних 13 остаются пять; спека добавляет правило, только когда открывает новый необратимый вред.
- Последнее слово за исполнителем: отказ судьи-модели — один раз; отклонённое читает тимлид на приёмке. Правило с двумя ложными отказами за плечо выключается на ретро.
- Jev ничего не блокирует. Метки копятся с v3.3; порог ставится, когда наберётся по 50 годных и 50 дефектных пунктов на вопрос; планка выхода из тени записывается до первого подсчёта.
