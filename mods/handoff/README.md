# handoff — мод Claude Code: хендофф и перенос в свежий контекст автоматически

Мод (плагин с функциональными хуками, Claude Code ≥ 2.1.287, Desktop ≥ 2.1.286) для two-tier-dev.

**Что делает.** После каждого хода читает заполнение контекста (`$.session.usage()`). Когда оно выше порога
(по умолчанию 70 %) — одним вызовом модели **над собственным транскриптом сессии** (`$.model.fork`, префикс
идёт из кэша промпта) пишет хендофф по нашему шаблону: что сделано · решения · следующее · открыто ·
строка свежей сессии. Файл — `<handoffDir>/handoff-<YYYY-MM-DD-HHMM>-<slug>.md`. Затем (`autoClear`)
выполняет `/clear` и сам отправляет первым сообщением «Прочитай <файл> и продолжай с раздела 3» —
работа идёт дальше в свежем контексте, руками ничего не набирается.

**Кнопки.** Полоса над промптом: `контекст 43% · хендофф @70%  [ Хендофф → свежий контекст ]  [ Только файл ]  Скрыть`.
Горячие клавиши, когда полоса держит фокус (ctrl+x tab): `h` — хендофф + `/clear` + продолжение, `f` — только файл.
При заполнении выше порога строка подсвечивается жёлтым; результат последнего действия показывается рядом.

**Команды.** `/handoff now` — то же, что кнопка · `/handoff write` — только файл и строка свежей сессии
(для нового процесса) · `/handoff status` — заполнение, порог, последний файл · `/handoff last`.
Строка статуса: `ctx 43% · handoff @70%`.

**Где не работает.** `claude -p` и SDK (нет человека у промпта — мод молчит); Cowork (моды там не
исполняются — хендофф тимлида остаётся за скиллом). Агенты воркфлоу и субагенты не трогаются.

**Настройки** (`/config` → handoff, или `pluginConfigs.handoff` в settings любого уровня — в репо тимлида
`.claude/settings.json` может задать `handoffDir: "claude"`):

| поле | по умолчанию | смысл |
|---|---|---|
| `threshold` | 70 | % заполнения окна, после которого хендофф пишется сам (10–95) |
| `handoffDir` | `handoffs` | каталог относительно корня проекта |
| `autoClear` | true | после файла — `/clear` и продолжение |
| `minTurns` | 2 | не хэндоффить раньше N промптов |
| `language` | `ru` | язык документа и строки продолжения (`ru` / `en`) |

**Предохранители.** Один хендофф за раз; повторно взводится, когда заполнение упало ниже `threshold − 20`
(после `/clear` так и будет); ошибка модели или файла — тост, ничего не очищается; при провале `/clear`
файл остаётся, тост называет причину.

**Установка из этого репо** (папка `mods/` — локальный marketplace; правка папки → `/reload-plugins`):

```sh
claude plugin marketplace add ~/Desktop/Projects/two-tier-dev/mods
claude plugin install handoff@two-tier-mods --scope user
```

**Проверка.** `claude plugin validate mods/handoff` · `claude plugin test mods/handoff` (8 тестов, включая полосу на terminal и desktop) ·
`tsc -p` по tsconfig из заголовка `claude-code.d.ts`.
