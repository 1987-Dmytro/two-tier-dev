# /plan-phase <n> — план фазы, потом СТОП

Читать `docs/SPEC-<n>.md` целиком и только те разделы других файлов, на которые он ссылается. Plan mode: ни одной правки, кроме самого плана. Писать `docs/PLAN-<n>.md` — четыре раздела, ничего сверх них.

## Файлы
Каждый файл, который фаза создаёт, переписывает или перемещает, сгруппированный по фиче, с источником содержимого (внешний источник verbatim · файл из этого репо с точной строкой · пишется заново). Семантика, которую SPEC не обязан называть — куда что ложится, — называется здесь.

## Порядок
Что задают метки `after:` и `[P]`, и какие зависимости SPEC **не** назвал: фича, которая читает файл, перемещаемый другой фичей, идёт до неё. Для группы `[P]` — множества записи каждой фичи; непересекающиеся множества и есть весь аргумент безопасности параллели.

## Риски
Ранжированные, у каждого ОДНА конкретная развязка. Нагруженное допущение, которое не измерено, называется `UNVERIFIED` вместе с тестом, который его закроет. Опровергнутое измерением в раздел не попадает.

## Доказательство
На каждую фичу: команда чека из SPEC verbatim · исполняемая форма с поимённым перечнем правок и причиной каждой · маркер · путь `docs/evidence/F<n>-<check>-result.txt`. Один идиом захвата на все чеки:

```
( set -o pipefail; { <КОМАНДА>; } 2>&1 | tee <абсолютный путь>/docs/evidence/F<n>-<check>-result.txt ); rc=$?
```

`tee` — вывод и в файл, и в транскрипт; `pipefail` — настоящий статус вместо нуля от `tee`; `2>&1` внутри скобок — иначе диагностика мимо файла; подоболочка слева от пайпа гасит `cd` и `exit` внутри чека; путь у `tee` абсолютный.

## Дельта Environment
Сверить таблицу Environment в `docs/PROCESS.md` со SPEC этой фазы и напечатать две строки:

```
поставить: <инструмент> — под <фичу/чек>, команда: <…>
убрать:    <инструмент> — ни одна фича фазы его не называет, команда: <…>
```

Инструмент входит только под названный чек или фичу. Дельту применяет исполнитель первым коммитом фазы, до первой фичи.

## Конец
Закоммитить `docs/PLAN-<n>.md` по пути (`git add docs/PLAN-<n>.md && git commit`), напечатать путь и СТОП. Реализацию не начинать: её открывает `/goal` оператора. Отклонение от плана по ходу фазы — обновить `docs/PLAN-<n>.md` тем же коммитом, что и отклонившуюся фичу.
