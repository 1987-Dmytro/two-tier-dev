# /plan-phase <n> — план фазы, потом стоп

Нужен только фазе с платными или необратимыми шагами: её PLAN тимлид принимает до запуска фазы. Обычная фаза пишет PLAN шагом 0 внутри своего запуска.

1. Прочитать `docs/SPEC-$ARGUMENTS.md` целиком и только те файлы, на которые он ссылается. Ничего, кроме плана, не править.
2. Написать `docs/PLAN-$ARGUMENTS.md` по `docs/PLAN.template.md`: файлы · порядок · риски · доказательство · отклонения. Только текущий план, не журнал поправок. Каждый платный или необратимый шаг — отдельной строкой: перед ним команда, которая может провалить сессию, и порог из `docs/PROCESS.md` §Деньги.
3. Дельта Environment — две строки в разделе «Файлы»: `поставить: <инструмент> — под <фичу>, команда …` и `убрать: <инструмент> — фаза его не называет, команда …`. Инструмент входит только под названный чек или фичу.
4. `bin/check-budget` → `BUDGET_OK`: PLAN не длиннее 150 строк.
5. `git add docs/PLAN-$ARGUMENTS.md && git commit -m "PLAN-$ARGUMENTS: шаг 0"`, напечатать путь и стоп. Реализацию открывает запуск фазы оператором — стартовый запрос `docs/PROMPT.txt` — после приёмки плана.
