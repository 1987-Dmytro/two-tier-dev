# CLAUDE.md — <проект>

**Факты проекта.** Стек: <…>. Запуск: `<команда>`. Чек: `<команда>`. Зачем — `intent/INTENT.md`; фаза — `docs/SPEC-<n>.md` и стартовый запрос `docs/PROMPT.txt`; механика проекта — `docs/PROCESS.md`; запуск — `docs/LAUNCH.md`.

**Твои файлы** — `docs/PLAN-<n>.md` и `docs/PROGRESS.md`. Голова PROGRESS — отчёт фазы: что сделано, следующий шаг оператора, когда закончим. Файлы тимлида (список `owner` в `budgets.json`) не правятся: их держат deny `Edit`, хук коммита и `bin/check-budget`.

**Пункт** — строка `F<n>.<k>` SPEC: у каждого проба с красной стороной; она печатает `F<n>.<k> <сырой вывод>` в `docs/evidence/<F>-<check>-result.txt`, маркер фичи — только после всех проверок. Id пункта — в начале сообщения коммита (`F2.3: …`).

**Чек** — команда и её вывод в транскрипте и в evidence; чек без вывода не пройден.

**Бюджеты** — `bin/check-budget` до коммита. Красное — ужать документ, а не поднять предел.

**Стоп** — `STOP: <id>` новой строкой в PROGRESS, рядом вопрос и resume-строка, закоммичено и запушено; после неё ход кончается. Развилка, которую SPEC не закрыл, — простейшее прочтение и строка в `## Notes`.

**Оператор** — файл `AGENT_STOP` в корне останавливает сессию; строка в `STEER.md` приходит заметкой к результату следующего вызова.

**Агенты воркфлоу** (ultracode — штатный режим) правят только в своих worktree (`isolation: 'worktree'`) или только читают. Коммит делает главная сессия, `git add` по точным путям. Push в `main` запрещён: `main` меняет оператор через PR после приёмки.

**Приёмка** — находки по `REVIEW.md`; вердикт выносит сохранённый воркфлоу `/verify-phase` (`bin/verify-phase`, свежий клон, 30 мин) из `/accept`: один полный круг, после починки — `bin/verify-phase F<n> …` только по затронутым фичам.

**Коммит судят код и `abide check`** — хук `.githooks/commit-msg` (`git config core.hooksPath .githooks`): секрет, почта или домашний путь в evidence, файл тимлида без «Тимлид:», удаление мимо `git mv` — отказ с правилом и файлом; затем `abide check` по рубрике `.abide/rubric.json`: отказ от 0,8 — один раз, починить и закоммитить снова. `.githooks/pre-push` отказывает force-push. `--no-verify` не используется.
